## 状态与数据边界

- 当前计划优先作为任务标题，只依据明确 `goal_id` 展示所属目标。
- 运行中、未结束、待验收、已完成各自表达。步骤完成与跳过分开计数；无步骤不伪造进度。
- 验证记录是证据，不能推断“验证通过”。服务进程状态与 HTTP 连接健康分开呈现。
- 加载、失败、未知和过期数据不显示为当前正常状态。
- 状态缓存按工作区和资源隔离。写操作响应先更新共享状态，后台旧结果不能覆盖用户操作。
- 配置保存只合并当前分组修改的字段；项目分组写入串行读取最新配置。保存失败保留草稿。
- 不迁移/清空工作区、计划、历史、密钥和界面偏好。旧路由映射见 [页面结构](./page-structure.json)。
