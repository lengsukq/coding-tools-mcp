# UI 架构与代码审查

检查日期：2026-10-07。基线：用户确认的全应用优化计划、`docs/ui/optimization-baseline.md`，Git `2757fce7fe0b415bd3f26b729b07c6e089726a61`。

## 实现与边界

- Vue/Tauri 与业务 IPC 保持原有契约；本轮未修改 Rust 后端、数据格式或持久化记录，不增加桌面任务创建接口。
- 前端资源所有权集中到 `async-resource.ts` 与 `workspace-status-cache.ts`，按工作区/资源类型隔离，请求去重、TTL、错误与代际失效共享。侧栏、工作台、概览、任务、诊断消费统一展示模型。
- 设置写入队列在模块作用域存活。全局设置保存捕获当前草稿与基线，再读取最新配置，只合并所属分类有变化的字段；工作区保存合并对应记录和字段，路径变化失效旧缓存。
- 路由负责工作区六页及应用设置五分类；旧连接/密钥/FRP/软件地址映射分类和区块。草稿注册覆盖路由离开、关闭和界面维护操作。
- 语义 token 收口至 design-system.css，删除 ios-vue.css/workbench.css 和十个无消费者组件；保留原品牌选择与偏好。

| 回归风险 | 处理与证据 |
| --- | --- |
| 共享缓存 HIGH、整应用范围 CRITICAL | 独立提交；14 项测试覆盖失效、旧请求、去重、TTL、错误保留；浏览器快速切换 Alpha/Beta 不串数据 |

## 图谱证据边界
