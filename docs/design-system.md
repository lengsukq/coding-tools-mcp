# 全应用设计规范（Design System 2.0）

本规范定义 Coding Tools MCP 的 **左侧悬浮毛玻璃岛 + 左侧二级分类导航 + 单屏专注拆页 + 全站全局搜索** 体系，核心服务于查看 AI 工作、处理阻塞、追溯代码变更、多设备联邦配对与人工验收。

## 唯一视觉来源

`src/styles/design-system.css` 统一定义语义令牌、三层光学层次、左侧二级导航轨（`.ui-subnav-layout` / `.ui-subnav-rail`）、Bento 网格与交互状态；`src/app.css` 负责全局字体与数字等宽排版（`tabular-nums`），`src/palette.css` 仅定义六套品牌强调色锚点。页面 `scoped` 样式仅负责局部网格约束。

## 信息架构：单屏拆页、侧边导航与全局搜索

- **严禁超长纵向堆叠**：每个页面只承载一个聚焦主题，严禁将网关、配对、密钥、代理或权限等多个独立领域纵向拼接成超长滚动页。
  - **应用设置**拆分为 4 大分组共 **15 个独立单屏子页**（网关与公网隧道、Gemini 客户端接入、服务名称与访问控制、局域网本机与共享、局域网设备发现与管理、共享认证密钥、FRP 服务器档案、默认权限与命令白名单、AI 指令与技能来源、Computer Use 屏幕授权、Computer Use 操控记录、网络代理、内置隧道组件、外观与启动、关于与系统维护）。
  - **工作区详情**拆分为 2 大分组共 **8 个独立子页**（概览、任务与验收、代码变更审阅、历史会话上下文、运行诊断日志 + 原“设置”拆出的项目信息与保护、执行权限与命令、AI 指令与历史记录）。
  - **工作台首页**按左侧分区切换为 **4 个专注单屏视图**（焦点与待处理、全部工作区矩阵、最近开发会话、传输用量分析）。
- **左侧二级分类导航轨（`.ui-subnav-rail`）**：主页面内部的多视图切换统一置于左侧 `224px` 吸顶雾面毛玻璃导航栏，不在内容顶部堆叠横向页签条或顶部锚点速跳条。
- **全站全局搜索（`⌘K / Ctrl+K`）**：`src/lib/global-search.ts` 与 `GlobalSearchDialog.vue` 提供跨任意页面的统一搜索入口（同步常驻于主侧边栏顶部），支持按中英文关键词直接跳转到任意设置子页、工作区及工作区具体子视图。

## 三层光学预算（3-Tier Matte Glass）与同心大圆角

为兼顾高对比度阅读质感与 macOS WebView 内存/滚动帧率，严格执行三层光学预算：

- **L0 环境光画布**：素净中性底色（浅色 `#edf1f6` / 深色 `#101620`）叠加低饱和度品牌色双光斑，长时间盯屏无视觉疲劳。
- **L1 悬浮玻璃岛与浮层**（`AppShell` 侧边栏、`GlobalSearchDialog`、`ModalDialog`、`ToastHost`）：四边留白 `12px`，圆角 `28px ~ 32px`，采用 `backdrop-filter: blur(26~30px) saturate(145~150%)` 与顶部 `1px` 镜面内高光。
- **L2 Bento 雾面主卡与二级导航轨**（`GlassCard`、`.ui-subnav-rail`）：圆角 `28px`，采用克制雾面半透明填充与 `blur(20px)`，支持 `default`、`focal`（焦点微渐变）、`subtle` 三档变体。
- **L3 零模糊高光内嵌层**（`.ui-inset`、`.ui-disclosure`、列表行、代码块）：圆角 `18px`（控件与行 `14px`），**禁止嵌套 `backdrop-filter`**，保证长列表 120fps 流畅滚动并控制显存占用。
- **L4 全胶囊交互控件**（`SegmentedControl`、`BaseButton`、`StatusPill`）：圆角 `999px`，具备按压微缩放与平滑高光选中态。

## 排版与响应式 Bento 网格

- 页面标题 `24~28px / -0.03em`，Bento 区块标题 `16.5px`，正文与标准控件 `14px`，辅助说明 `12~12.5px`；端口、耗时、计数与版本号统一启用 `tabular-nums`。
- 内容区 `≥1000px` 采用左侧二级导航轨 + 右侧专注内容台（`.ui-subnav-layout`）及非对称 Bento 双栏（`.ui-bento-grid`）；`<1000px` 通过容器查询（`@container`）平滑收拢为流式单列。

## 状态口径与热更新体验

- 同一份 `ui-model` 定义任务焦点、中文状态与步骤进度；计划标题优先，关联目标作为上下文说明；完成与跳过分别计数，零步骤不显示虚假进度。
- 全局连接、认证模式、MCP 服务名称与共享密钥保存后优先通过内存策略热更新或按需平滑重载生效，前端明确反馈实时应用状态。

开发环境 `/dev/ui` 提供组件画廊基准页；生产环境不注册该地址。
